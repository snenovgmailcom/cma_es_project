# `analysis/` — Tables and figures

Scripts that turn the `experiments/` result tree
(`<suite>/d<dim>/<ALGO>/maxevals_<N>/{fK.pkl, summary.csv}`) into the tables and
figures of the paper. Run from the repository root.

## Module map

| File | Produces |
|---|---|
| `summary_grid_clean.py` | Per-dimension and per-class summed totals — SUM(Mean), SUM(Median), SUM(Std.), SUM(Minimum), SUM(Maximum), and SUM(FBTC(B)) — over a common cell set, with partial-coverage warnings. |
| `summary_grid.py` | Legacy/alternate summed-grid implementation with the same aggregate metrics plus per-target hit counts THR_k. |
| `run_mwu_all_functions.py` | Current inference pipeline: independent two-sided Mann–Whitney U tests on the 51 run-wise terminal errors, with Bonferroni correction over functions separately for each setting and competitor; also renders existing DSC results. |
| `compare.py` | Legacy exploratory utility using paired two-sided Wilcoxon signed-rank tests; Benjamini–Hochberg is the default correction, with Bonferroni and no correction also available. It is not used for the current supplementary MWU results. |
| `budget_slopes.py` | Per-function low-vs-high-budget slope panel for one (suite, dim, function class). |
| `fig_budget_slopes.py` | Composed multi-panel budget-slope figures for selected algorithms. |
| `class_rank_figures.py` | Two publication figures: mean (Friedman-style) rank per algorithm, and a per-class heatmap of where the profile holds. |
| `make_cell_readme.py` | Legacy CEC2020 D=5 README generator with hard-coded function classes; current cell reports are generated by `cell_report.py`. |
| `cell_report.py` | Current per-cell report generator: ranking figures, budget-scaling figures, and `README.md`. |
| `suite_report.py` | Current per-suite report generator: per-dimension figures and cross-dimension `README.md`. |
| `report_style.py` | Shared reader-facing algorithm names, class labels, metric labels, budget formatting, and reporting notes. |
| `audit_report_style.py` | Audits README reporting against the shared presentation rules. |
| `__init__.py` | Package marker. |

`FBTC(B)` denotes Fixed-Budget Target Coverage at evaluation budget `B`.
For each function, terminal errors are first subjected to the numerical-zero
rule `|error| <= 1e-8 -> 0`. For each of 51 log-uniform targets from `1e+2` to
`1e-8`, the success rate is the fraction of runs whose terminal error reaches
that target; FBTC(B) is the mean of these 51 success rates. The experiments use
51 runs per function. Class and dimension aggregates sum the per-function
FBTC(B) values. Each budget is evaluated separately; FBTC(B) is not an anytime
measure.

## Usage

The exact flags differ per script; pass `--help` to any of them. Representative
calls:

**Summed tables (per-dimension / per-class):**

```bash
python analysis/summary_grid_clean.py --csv <combined_summary.csv>
python analysis/summary_grid.py       --csv <combined_summary.csv>
```

**Per-function significance vs a reference (e.g. MSC-CMA-ES):**

```bash
python analysis/compare.py --help     # base directory, reference algo, metric, alpha
```

**Budget-slope figures:**

```bash
# single (suite, dim, class) panel
python analysis/budget_slopes.py --suite cec2017 --dim 10 \
    --low 100000 --high 1000000 --metric median --func-class composition --out figs

# composed multi-panel figure (the version used in the paper)
python analysis/fig_budget_slopes.py --suite cec2017 --dim 10 \
    --b-lo 100000 --b-hi 1000000 --algos MSC-CMA,BIPOP-CMA \
    --func-class composition --official 100000 --out figures/slopes_cec2017_d10.png
```

**Per-class rank / heatmap figures:**

```bash
python analysis/class_rank_figures.py --metric mean --out figs
```

**Regenerate a cell's README from its pkls:**

```bash
python analysis/make_cell_readme.py --base-dir experiments/cec2020/d5/MSC-CMA \
    --maxevals 50000
```

## Inputs and outputs

- **Inputs:** the per-cell results under `experiments/` (the `.pkl` per-seed
  errors and the `summary.csv` aggregates). The grid scripts read a combined
  CSV via `--csv`; the figure scripts read the `experiments/` tree directly via
  `--root` (default `experiments`).
- **Outputs:** the table scripts print to stdout; the figure scripts save PNGs
  (default directory `figs/`, or an explicit `--out` path).
